# Проверка экспорта Forma 3D

Дата: 14 октября 2026 года.

Исходная версия: `60fa4319a11ffe6dd73b9a7f3dac8bb18dd6447f`. Экспорт адаптирован для обычного Node.js и Docker. В мобильном меню также обновлено название Forma 3D и исправлена подпись INFORMATION.

Пройденные проверки:

- TypeScript: `tsc --noEmit --incremental false` — без ошибок.
- `next build --webpack` — production-сборка завершена успешно, создан standalone-сервер.
- Согласованность `package.json` и `pnpm-lock.yaml` — проверена в отдельной чистой директории с frozen lockfile. Установка зависимостей из интернета в этой среде не выполнялась; для сборки использованы уже установленные версии из зафиксированного графа.
- Production-сервер запущен через `scripts/start.mjs` на пользовательском `PORT=43127`.
- Главная, русская и узбекская версии каталога, карточка расходника и контакты — 6 маршрутов вернули HTTP 200.
- Все 88 файлов из `public/` — HTTP 200 и точное совпадение содержимого.
- 10 подключённых файлов CSS/JavaScript — HTTP 200.
- `/api/health` — HTTP 200, статус `ok`.
- Исходники размещённого сайта не изменялись при подготовке экспорта.

Ограничения проверки: Docker в этой среде недоступен, образ здесь не собирался; развёртывание в Railway и браузерная проверка интерфейса в рамках экспорта не выполнялись. Для локальной проверки в ограниченной среде применён только диагностический обход недоступного системного показателя RSS; он не менял код приложения и не входит в архив. В обычной среде Docker используется стандартная команда сборки Next.js без этого обхода.
